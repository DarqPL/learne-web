# Phase 2 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hoàn tất UI Phase 2 (login, đăng ký OTP, quên/đặt lại mật khẩu, đổi mật khẩu, buộc đổi mật khẩu lần đầu, layout theo role, Admin tạo Teacher) dùng đúng các API auth hiện có của backend.

**Architecture:** React + Vite + TypeScript. Routing bằng `react-router-dom`, styling bằng Tailwind CSS v4. Auth state qua React Context; access token chỉ nằm trong memory (module singleton). Axios instance với response interceptor xử lý refresh-on-401 single-flight (một promise refresh dùng chung, retry request sau khi refresh, logout khi refresh thất bại). Kết nối backend qua Vite proxy `/api` → `http://localhost:8080` (cookie same-origin, không cần CORS).

**Tech Stack:** React 19, Vite 8, TypeScript, react-router-dom, axios, tailwindcss v4 (@tailwindcss/vite).

**Spec:** `docs/superpowers/specs/2026-08-18-phase2-ui-design.md`

**Ghi chú môi trường:** Cần chạy `npm install` trước khi `npm run build` / `npm run lint`. Backend chạy trên `localhost:8080` (Docker Compose dev từ `infra/docker-compose.dev.yml`). Frontend chạy trên `localhost:5173`.

**Quy ước code:** `tsconfig.app.json` bật `verbatimModuleSyntax` (bắt buộc `import type` cho type-only) và `erasableSyntaxOnly` (không dùng enum, dùng union type). ESLint bật `reactRefresh/only-export-components` → file component chỉ export component (hàm tiện ích đặt file riêng không JSX).

```ts
type Listener = (token: string | null) => void

let accessToken: string | null = null
const listeners = new Set<Listener>()

export const tokenStore = {
  get(): string | null {
    return accessToken
  },
  set(token: string | null): void {
    accessToken = token
    listeners.forEach((listener) => listener(token))
  },
  clear(): void {
    accessToken = null
    listeners.forEach((listener) => listener(null))
  },
  subscribe(listener: Listener): () => void {
    listeners.add(listener)
    return () => {
      listeners.delete(listener)
    }
  },
}
```

### Task 3: Axios client với refresh-on-401 single-flight

**Files:**
- Create: `src/lib/api/client.ts`

- [ ] **Step 1: Tạo src/lib/api/client.ts**

```ts
import axios from 'axios'
import type { AxiosError, AxiosRequestConfig } from 'axios'
import { tokenStore } from '../auth/tokenStore'
import type { AuthTokenResponse } from './types'

export const http = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL ?? '',
  withCredentials: true,
  headers: { 'Content-Type': 'application/json' },
})

interface RetriableConfig extends AxiosRequestConfig {
  _retried?: boolean
}

const PUBLIC_PATHS = new Set<string>([
  '/api/auth/login',
  '/api/auth/refresh',
  '/api/auth/register/request-otp',
  '/api/auth/register/verify-otp',
  '/api/auth/register/resend-otp',
  '/api/auth/password-reset/request',
  '/api/auth/password-reset/confirm',
])

function isPublicPath(url: string): boolean {
  return PUBLIC_PATHS.has(url.split('?')[0])
}

let refreshPromise: Promise<AuthTokenResponse> | null = null
let unauthorizedHandler: (() => void) | null = null

export function setUnauthorizedHandler(handler: () => void): void {
  unauthorizedHandler = handler
}

async function doRefresh(): Promise<AuthTokenResponse> {
  const response = await http.post<AuthTokenResponse>('/api/auth/refresh')
  tokenStore.set(response.data.accessToken)
  return response.data
}

export function refreshAccessToken(): Promise<AuthTokenResponse> {
  if (!refreshPromise) {
    refreshPromise = doRefresh().finally(() => {
      refreshPromise = null
    })
  }
  return refreshPromise
}

http.interceptors.request.use((config) => {
  const token = tokenStore.get()
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

http.interceptors.response.use(
  (response) => response,
  async (error: AxiosError) => {
    const { response, config } = error
    if (
      !config ||
      !response ||
      response.status !== 401 ||
      isPublicPath(config.url ?? '') ||
      (config as RetriableConfig)._retried === true
    ) {
      return Promise.reject(error)
    }
    try {
      const { accessToken } = await refreshAccessToken()
      const retryConfig = {
        ...config,
        _retried: true,
        headers: {
          ...config.headers.toJSON(),
          Authorization: `Bearer ${accessToken}`,
        },
      } as RetriableConfig
      return http.request(retryConfig)
    } catch (refreshError) {
      tokenStore.clear()
      unauthorizedHandler?.()
      return Promise.reject(refreshError)
    }
  },
)

export function getApiErrorMessage(error: unknown, fallback: string): string {
  if (axios.isAxiosError(error)) {
    const data = error.response?.data as { message?: string } | undefined
    if (data?.message) {
      return data.message
    }
    if (error.response?.status === 401) {
      return 'Phiên đăng nhập hết hạn, vui lòng đăng nhập lại.'
    }
  }
  return fallback
}
```

Giải thích: `refreshAccessToken()` là **single-flight** — mọi request 401 đồng thời await cùng một promise `refreshPromise` nên chỉ có 1 lần gọi `POST /api/auth/refresh`. Cờ `_retried` chặn vòng lặp retry khi access token mới vẫn bị 401 (vd tài khoản khóa). Khi refresh thất bại → xóa token + gọi `unauthorizedHandler` (AuthProvider xử lý logout).

- [ ] **Step 3: Tạo src/lib/auth/AuthProvider.tsx**

```tsx
import { useCallback, useEffect, useMemo, useState, type ReactNode } from 'react'
import { refreshAccessToken, setUnauthorizedHandler } from '../api/client'
import { tokenStore } from './tokenStore'
import { AuthContext } from './auth-context'
import type { AuthUser } from '../api/types'

export function AuthProvider({ children }: { children: ReactNode }) {
  const [user, setUser] = useState<AuthUser | null>(null)
  const [isInitializing, setIsInitializing] = useState(true)

  const handleLogout = useCallback(() => {
    tokenStore.clear()
    setUser(null)
  }, [])

  useEffect(() => {
    setUnauthorizedHandler(handleLogout)
    let cancelled = false
    refreshAccessToken()
      .then((data) => {
        if (!cancelled) {
          setUser(data.user)
        }
      })
      .catch(() => {})
      .finally(() => {
        if (!cancelled) {
          setIsInitializing(false)
        }
      })
    return () => {
      cancelled = true
    }
  }, [handleLogout])

  const value = useMemo(
    () => ({
      user,
      isInitializing,
      login: (accessToken: string, expiresInSeconds: number, nextUser: AuthUser) => {
        void expiresInSeconds
        tokenStore.set(accessToken)
        setUser(nextUser)
      },
      logout: handleLogout,
    }),
    [user, isInitializing, handleLogout],
  )

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>
}
```

Giải thích: khi mount, provider thử `refreshAccessToken()` để khôi phục phiên từ cookie refresh (token mất sau reload). Nếu thất bại → coi như chưa đăng nhập. `setUnauthorizedHandler(handleLogout)` nối callback để interceptor có thể logout khi refresh bị lỗi trong lúc chạy.

```tsx
import { Navigate, Outlet } from 'react-router-dom'
import { useAuth } from './auth-context'
import { homePathFor } from './routes'
import { Spinner } from '../../components/ui/Spinner'
import type { UserRole } from '../api/types'

function FullPageSpinner() {
  return (
    <div className="flex min-h-screen items-center justify-center">
      <Spinner />
    </div>
  )
}

export function RequireAuth() {
  const { user, isInitializing } = useAuth()
  if (isInitializing) {
    return <FullPageSpinner />
  }
  if (!user) {
    return <Navigate to="/login" replace />
  }
  return <Outlet />
}

export function RequireRole({ role }: { role: UserRole }) {
  const { user } = useAuth()
  if (user && user.role !== role) {
    return <Navigate to={homePathFor(user.role)} replace />
  }
  return <Outlet />
}

export function RequirePasswordChange() {
  const { user } = useAuth()
  if (user?.mustChangePassword) {
    return <Navigate to="/change-password?forced=1" replace />
  }
  return <Outlet />
}

export function RootRedirect() {
  const { user, isInitializing } = useAuth()
  if (isInitializing) {
    return <FullPageSpinner />
  }
  return <Navigate to={user ? homePathFor(user.role) : '/login'} replace />
}
```

```tsx
import { useState, type FormEvent } from 'react'
import { Link, useNavigate } from 'react-router-dom'
import { requestRegistrationOtp, resendRegistrationOtp, verifyRegistrationOtp } from '../../lib/api/authApi'
import { getApiErrorMessage } from '../../lib/api/client'
import { Alert } from '../../components/ui/Alert'
import { Button } from '../../components/ui/Button'
import { Card } from '../../components/ui/Card'
import { Field } from '../../components/ui/Field'
import { Input } from '../../components/ui/Input'
import { PasswordInput } from '../../components/ui/PasswordInput'

interface RegistrationForm {
  fullName: string
  email: string
  password: string
  confirmPassword: string
}

const initialForm: RegistrationForm = {
  fullName: '',
  email: '',
  password: '',
  confirmPassword: '',
}

export function RegisterPage() {
  const navigate = useNavigate()
  const [step, setStep] = useState<1 | 2>(1)
  const [form, setForm] = useState<RegistrationForm>(initialForm)
  const [otp, setOtp] = useState('')
  const [error, setError] = useState<string | null>(null)
  const [info, setInfo] = useState<string | null>(null)
  const [submitting, setSubmitting] = useState(false)

  const setField = (name: keyof RegistrationForm, value: string) => {
    setForm((prev) => ({ ...prev, [name]: value }))
  }

  const validateStep1 = (): string | null => {
    if (form.fullName.trim().length === 0) {
      return 'Vui lòng nhập họ và tên.'
    }
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(form.email)) {
      return 'Email không hợp lệ.'
    }
    if (form.password.length < 8 || !/[a-zA-Z]/.test(form.password) || !/[0-9]/.test(form.password)) {
      return 'Mật khẩu phải có ít nhất 8 ký tự và gồm cả chữ và số.'
    }
    if (form.password !== form.confirmPassword) {
      return 'Mật khẩu xác nhận không khớp.'
    }
    return null
  }

  const handleRequestOtp = async (event: FormEvent) => {
    event.preventDefault()
    const validationError = validateStep1()
    if (validationError) {
      setError(validationError)
      return
    }
    setError(null)
    setInfo(null)
    setSubmitting(true)
    try {
      await requestRegistrationOtp(form)
      setInfo('Mã OTP đã được gửi đến email của bạn. Vui lòng kiểm tra hộp thư (kể cả thư rác).')
      setStep(2)
    } catch (err) {
      setError(getApiErrorMessage(err, 'Không thể gửi mã OTP. Vui lòng thử lại.'))
    } finally {
      setSubmitting(false)
    }
  }

  const handleResendOtp = async () => {
    setError(null)
    setSubmitting(true)
    try {
      await resendRegistrationOtp({ email: form.email })
      setInfo('Mã OTP mới đã được gửi đến email của bạn.')
    } catch (err) {
      setError(getApiErrorMessage(err, 'Không thể gửi lại mã OTP. Vui lòng thử lại.'))
    } finally {
      setSubmitting(false)
    }
  }

  const handleVerifyOtp = async (event: FormEvent) => {
    event.preventDefault()
    setError(null)
    setSubmitting(true)
    try {
      await verifyRegistrationOtp({ email: form.email, otp })
      navigate('/login', { replace: true, state: { message: 'Đăng ký thành công, vui lòng đăng nhập.' } })
    } catch (err) {
      setError(getApiErrorMessage(err, 'Mã OTP không hợp lệ.'))
    } finally {
      setSubmitting(false)
    }
  }

  if (step === 2) {
    return (
      <Card>
        <h1 className="mb-6 text-center text-2xl font-bold text-gray-900">Xác nhận OTP</h1>
        <p className="mb-4 text-sm text-gray-600">
          Mã OTP đã được gửi đến <span className="font-medium">{form.email}</span>
        </p>
        {info ? (
          <div className="mb-4">
            <Alert variant="success">{info}</Alert>
          </div>
        ) : null}
        {error ? (
          <div className="mb-4">
            <Alert>{error}</Alert>
          </div>
        ) : null}
        <form onSubmit={handleVerifyOtp} className="space-y-4">
          <Field label="Mã OTP (6 chữ số)">
            <Input
              inputMode="numeric"
              maxLength={6}
              value={otp}
              onChange={(event) => setOtp(event.target.value)}
              placeholder="123456"
              required
            />
          </Field>
          <Button type="submit" loading={submitting} className="w-full">
            Xác nhận
          </Button>
        </form>
        <div className="mt-4 flex justify-between text-sm">
          <button
            type="button"
            onClick={handleResendOtp}
            disabled={submitting}
            className="text-indigo-600 hover:underline disabled:opacity-60"
          >
            Gửi lại mã OTP
          </button>
          <button
            type="button"
            onClick={() => {
              setStep(1)
              setOtp('')
            }}
            className="text-gray-600 hover:underline"
          >
            Sửa thông tin
          </button>
        </div>
      </Card>
    )
  }

  return (
    <Card>
      <h1 className="mb-6 text-center text-2xl font-bold text-gray-900">Đăng ký tài khoản</h1>
      {error ? (
        <div className="mb-4">
          <Alert>{error}</Alert>
        </div>
      ) : null}
      <form onSubmit={handleRequestOtp} className="space-y-4">
        <Field label="Họ và tên">
          <Input value={form.fullName} onChange={(event) => setField('fullName', event.target.value)} required autoComplete="name" />
        </Field>
        <Field label="Email">
          <Input
            type="email"
            value={form.email}
            onChange={(event) => setField('email', event.target.value)}
            required
            autoComplete="email"
            placeholder="ban@example.com"
          />
        </Field>
        <Field label="Mật khẩu">
          <PasswordInput value={form.password} onChange={(event) => setField('password', event.target.value)} required autoComplete="new-password" />
        </Field>
        <Field label="Xác nhận mật khẩu">
          <PasswordInput
            value={form.confirmPassword}
            onChange={(event) => setField('confirmPassword', event.target.value)}
            required
            autoComplete="new-password"
          />
        </Field>
        <p className="text-xs text-gray-500">Mật khẩu phải có ít nhất 8 ký tự, gồm cả chữ và số.</p>
        <Button type="submit" loading={submitting} className="w-full">
          Tiếp tục
        </Button>
      </form>
      <p className="mt-4 text-center text-sm text-gray-600">
        Đã có tài khoản?{' '}
        <Link to="/login" className="text-indigo-600 hover:underline">
          Đăng nhập
        </Link>
      </p>
    </Card>
  )
}
```

```tsx
import { useState, type FormEvent } from 'react'
import { useNavigate, useSearchParams } from 'react-router-dom'
import { changePassword, logout } from '../../lib/api/authApi'
import { getApiErrorMessage } from '../../lib/api/client'
import { useAuth } from '../../lib/auth/auth-context'
import { Alert } from '../../components/ui/Alert'
import { Button } from '../../components/ui/Button'
import { Card } from '../../components/ui/Card'
import { Field } from '../../components/ui/Field'
import { PasswordInput } from '../../components/ui/PasswordInput'

export function ChangePasswordPage() {
  const { logout: clearAuth } = useAuth()
  const navigate = useNavigate()
  const [searchParams] = useSearchParams()
  const forced = searchParams.get('forced') === '1'
  const [currentPassword, setCurrentPassword] = useState('')
  const [newPassword, setNewPassword] = useState('')
  const [confirmNewPassword, setConfirmNewPassword] = useState('')
  const [error, setError] = useState<string | null>(null)
  const [submitting, setSubmitting] = useState(false)

  const handleSubmit = async (event: FormEvent) => {
    event.preventDefault()
    setError(null)
    setSubmitting(true)
    try {
      await changePassword({ currentPassword, newPassword, confirmNewPassword })
      try {
        await logout()
      } catch {
        // refresh token đã bị thu hồi ở backend, bỏ qua lỗi
      }
      clearAuth()
      navigate('/login', { replace: true, state: { message: 'Đổi mật khẩu thành công, vui lòng đăng nhập lại.' } })
    } catch (err) {
      setError(getApiErrorMessage(err, 'Đổi mật khẩu thất bại.'))
    } finally {
      setSubmitting(false)
    }
  }

  return (
    <div className="flex min-h-screen items-center justify-center bg-gray-50 px-4">
      <Card>
        <h1 className="mb-2 text-center text-2xl font-bold text-gray-900">
          {forced ? 'Bắt buộc đổi mật khẩu' : 'Đổi mật khẩu'}
        </h1>
        {forced ? (
          <p className="mb-4 text-center text-sm text-gray-600">
            Bạn cần đổi mật khẩu trước khi sử dụng hệ thống.
          </p>
        ) : null}
        {error ? (
          <div className="mb-4">
            <Alert>{error}</Alert>
          </div>
        ) : null}
        <form onSubmit={handleSubmit} className="space-y-4">
          <Field label="Mật khẩu hiện tại">
            <PasswordInput
              value={currentPassword}
              onChange={(event) => setCurrentPassword(event.target.value)}
              required
              autoComplete="current-password"
            />
          </Field>
          <Field label="Mật khẩu mới">
            <PasswordInput value={newPassword} onChange={(event) => setNewPassword(event.target.value)} required autoComplete="new-password" />
          </Field>
          <Field label="Xác nhận mật khẩu mới">
            <PasswordInput
              value={confirmNewPassword}
              onChange={(event) => setConfirmNewPassword(event.target.value)}
              required
              autoComplete="new-password"
            />
          </Field>
          <p className="text-xs text-gray-500">Mật khẩu phải có ít nhất 8 ký tự, gồm cả chữ và số.</p>
          <Button type="submit" loading={submitting} className="w-full">
            {forced ? 'Đổi mật khẩu' : 'Cập nhật mật khẩu'}
          </Button>
        </form>
      </Card>
    </div>
  )
}
```

Giải thích luồng forced: Teacher đăng nhập lần đầu với mật khẩu tạm → `user.mustChangePassword=true` → LoginPage redirect `/change-password?forced=1`. Guard `RequirePasswordChange` chặn mọi trang protected khác về lại trang này. Sau khi đổi thành công, backend thu hồi mọi refresh token → frontend logout + redirect `/login`.

```tsx
import { useState, type FormEvent } from 'react'
import { adminCreateTeacher } from '../../lib/api/authApi'
import { getApiErrorMessage } from '../../lib/api/client'
import { Alert } from '../../components/ui/Alert'
import { Button } from '../../components/ui/Button'
import { Field } from '../../components/ui/Field'
import { Input } from '../../components/ui/Input'

export function CreateTeacherPage() {
  const [email, setEmail] = useState('')
  const [fullName, setFullName] = useState('')
  const [info, setInfo] = useState<string | null>(null)
  const [error, setError] = useState<string | null>(null)
  const [submitting, setSubmitting] = useState(false)

  const handleSubmit = async (event: FormEvent) => {
    event.preventDefault()
    setError(null)
    setInfo(null)
    setSubmitting(true)
    try {
      const response = await adminCreateTeacher({ email, fullName })
      setInfo(
        `Đã tạo tài khoản giảng viên ${response.data.fullName} (${response.data.email}). Mật khẩu tạm đã được gửi qua email.`,
      )
      setEmail('')
      setFullName('')
    } catch (err) {
      setError(getApiErrorMessage(err, 'Không thể tạo tài khoản giảng viên.'))
    } finally {
      setSubmitting(false)
    }
  }

  return (
    <div className="mx-auto max-w-md">
      <h1 className="mb-6 text-2xl font-bold text-gray-900">Tạo tài khoản giảng viên</h1>
      {info ? (
        <div className="mb-4">
          <Alert variant="success">{info}</Alert>
        </div>
      ) : null}
      {error ? (
        <div className="mb-4">
          <Alert>{error}</Alert>
        </div>
      ) : null}
      <form onSubmit={handleSubmit} className="space-y-4 rounded-2xl border border-gray-200 bg-white p-6 shadow-sm">
        <Field label="Họ và tên">
          <Input value={fullName} onChange={(event) => setFullName(event.target.value)} required autoComplete="off" />
        </Field>
        <Field label="Email">
          <Input
            type="email"
            value={email}
            onChange={(event) => setEmail(event.target.value)}
            required
            autoComplete="off"
            placeholder="giangvien@example.com"
          />
        </Field>
        <Button type="submit" loading={submitting} className="w-full">
          Tạo tài khoản
        </Button>
      </form>
    </div>
  )
}
```
